# 1. Управление доступом (приоритет: критичный)
## Нарушен контроль данных
* Есть несколько точек регистрации нового клиента, координации между этими точками нет.
* Со стороны систем обработки данных нет ограничений на доступ к данным.
* Риск несанкционированного доступа к персональным данным.

# 2. Безопасность данных (приоритет: критичный)
* Внутренние потоки данных между IT-продуктами контролируются не системно.
* Проблема управления и хранения потоков данных блокирует реализацию новых продуктов, основанных на данных.

# 3. Защита инфраструктуры (приоритет: высокий)
* Часть продуктов развернуты в гибриде
* Доступ в систему для внешних пользователей (клиентов и собственников) осуществляется через межсетевой экран (firewall).
* Рисков сетевых атак на ЦОД и облачные сервисы.

# 4. Управление инцидентами (приоритет: высокий)
* Утечка данных у конкурента. Нужно предотвратить подобные инциденты.
* Компания столкнулась с жалобами клиентов: они видят в приложении ошибки, когда заходят в личный кабинет. Там иногда могут отображаться данные другого клиента — например, другое Ф. И. О.
* Отсутсвует мониторинг.

# 5. Специфические аспекты (приориет: средний)
* Контроль мобильных приложений для собственников.
* Соблюдение требований ФЗ-152
